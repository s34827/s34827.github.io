Core Path

เส้นทางที่สนใจ

เภสัชศาสตร์ • การแพทย์ • วิทยาศาสตร์การทดลอง • การเขียนโปรแกรมเพื่อช่วยคิดวิเคราะห์และจัดการข้อมูล

HTML CSS JavaScript Python คิดวิเคราะห์ ทำงานเป็นทีม

ผลงานเด่น

01 · Inquiry

โครงงานวิทยาศาสตร์และการคำนวณ

ศึกษาการแก้ปัญหาด้วยกระบวนการทางวิทยาศาสตร์และการเขียนโปรแกรม ฝึกคิดวิเคราะห์ ทำงานเป็นทีม และนำเสนอผลอย่างเป็นระบบ

02 · Practice

กิจกรรมและเกียรติบัตร

เข้าร่วมการแข่งขัน กิจกรรมวิชาการ และค่ายวิทยาศาสตร์ เพื่อขยายประสบการณ์จริงนอกห้องเรียน

03 · Skill

ทักษะที่สนใจ

ผสานความรู้ด้านวิทยาศาสตร์สุขภาพเข้ากับทักษะดิจิทัล เพื่อเตรียมความพร้อมสู่การศึกษาต่อสายเภสัชศาสตร์
